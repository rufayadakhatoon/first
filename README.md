#Chatbot

The Local Desktop Chat Interface is a lightweight cross-platform desktop application built entirely in Python using the built-in Tkinter library. The project acts as a functional demonstration of creating structured Graphical User Interfaces (GUIs) and managing event-driven workflows without relying on external dependencies or third-party web installations.The application operates 100% locally on the host machine. It processes user statements using fundamental programming logic (string formatting and pattern-matching rules), making it highly secure, completely offline, and fast.
